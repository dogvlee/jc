## 0. 一句话决策

**商跃标签卖的是一套独立的本地标签工具：选纸、改字、扫码、连机、打印。它兼容精臣 / NIIMBOT 常见热敏机，但不是精臣官方应用，也不出售精臣的模板库。**

对外可承诺的内容只有三类：

1. 商跃自己画的入门模板（结构在本仓库 `template-layouts.js`，且占位文案已去掉精臣字样）。
2. 用户自己做的、或用户自己导入的模板。
3. 打印机协议兼容（D11 / D110 / B1 / B21 系列，以真机矩阵为准）。

精臣公开目录、固化在线包、导入的 NIIM JSON、OSS 素材，一律视为「精臣来源」。来源字段不可因改名、改分类、改 blurb 而消失。没有书面再分发授权前，这些内容不得进入对外 RC，也不得出现在「商跃模板 / 官方 / 精选」货架。

## 1. 产品卖什么

### 1.1 品类

| 项 | 定义 |
| --- | --- |
| 中文名 | 商跃标签 |
| 对外一句 | 给热敏标签机用的本地设计与打印工具 |
| 载体（RC） | 微信小程序 |
| 后续载体 | Android / Web（`niim-label-app`），不在本轮 RC |
| 付费模式（RC） | 免费工具，无账号、无会员、无模板店 |
| 数据模式 | 本地优先。标签、项目、历史只在本机 |

我们卖的是**完成一次出纸的能力**，不是精臣内容生态的镜像。

用户买（或下载）商跃，是为了：

- 在手机上把价签、货架、效期、线缆、姓名条做出来；
- 连上手里已有的精臣热敏机打出来；
- 下次还能从「最近标签」30 秒重打；
- 不注册、不上云、不把商品价和条码交给别人。

### 1.2 明确不卖

| 不卖 | 原因 |
| --- | --- |
| 精臣 / NIIMBOT 官方身份 | 仓库无品牌授权；现首页「N」标和「精臣标签」必须撤 |
| 精臣 9,161 套在线行业模板 | 来自 `print.niimbot.com`，客户端还带 `niimbot-user-agent: AppVersionName/6.6.6` |
| 153 套固化在线包 + 4 套 NIIM 导入包 | `source: online-niim` / `niim-import`，不是商跃作品 |
| 精臣 VIP / 付费素材货架 | 记录里的 `vip` / `hasVipRes` 是精臣权益，商跃不得转售或去标后当免费赠品 |
| 精臣耗材商城、固件升级、账号云同步 | 超出工具定位，且会把产品绑回精臣账号体系 |
| 「190 个商跃模板」这种说法 | 完整工程目录现为 211 = 54 个内置结构（其中 22 个已登记原创）+ 4 导入 + 153 固化精臣包，不能整包算原创 |

兼容打印机 ≠ 获得内容授权。协议能打，不代表模板能发。

### 1.3 对谁、解决什么

沿用现有 JTBD，只改归属：

| 角色 | 要完成的事 | 商跃给的 | 不靠精臣内容库 |
| --- | --- | --- | --- |
| 小店 | 改价、改条码、批量出签 | 价签类自有模板 + CSV + 扫码填入 | 不靠「价签-外套」等线上包 |
| 仓储 / 办公 | 货位、资产、线缆唯一码 | 仓储/线缆自有模板 + 序列号 | 不靠国网等导入样张当官方 |
| 家庭 | 收纳、效期、姓名条 | 生活类自有模板 + 空白画布 | 不靠精臣生活馆素材 |
| 回访用户 | 再打一张同样的 | 最近项目、打印历史、本地备份 | 与模板来源无关 |

成功标准（对外口径，替换「189 个系统模板」）：

- 新用户 3 分钟内：空白或**商跃模板** → 编辑 → 打印预检。
- 回访 30 秒内从最近标签再打。
- 10 类元素可用。
- 超打印头或未知机型发送前阻断，不静默裁切。
- 蓝牙假连接、开关切换、进程被杀有恢复路径。
- 用户能分清：这是商跃做的模板，还是我自己存的，还是（若未来授权）精臣来源。

## 2. 应用品牌

### 2.1 名称与话术

| 场景 | 用 | 禁用 |
| --- | --- | --- |
| 小程序名称 / 导航栏 / Web title | 商跃标签 | 精臣标签、精臣云、NIIMBOT、精臣风格 |
| 副标题 | 选纸 · 改字 · 连机 · 打印 | 精臣官方、原厂模板、官方同款 |
| 兼容说明（设置 / 帮助 / 预检） | 支持常见精臣 / NIIMBOT 热敏机（D11、D110、B1、B21 等，以已测机型为准） | 精臣官方应用、NIIMBOT 授权出品 |
| 关于页 | 商跃标签是独立产品，与精臣科技无隶属或代理关系 | 任何暗示官方、联名、OEM 的句子 |
| 微信类目建议 | 工具 — 信息查询 / 办公（以审核当时可过类目为准） | 不得占用精臣已注册商标作名称主体 |

对外一句完整表述：

> 商跃标签是独立的标签设计与蓝牙打印工具，兼容常见精臣热敏打印机。应用内「商跃模板」由商跃制作。「我的模板」是你自己保存的内容。

### 2.2 视觉识别（RC 最低要求）

当前实现不能直接上架：

- 首页 lockup 字母 **N** + 文案「精臣标签」（`pages/home/index.wxml`）。
- `app.json` `navigationBarTitleText`: 精臣标签。
- Web `index.html` title / description：精臣标签、精臣风格。
- 主题色与红顶 Hero 明显贴近精臣 App，RC 对内体验版可暂留结构，**对外提交审核前必须换标、换名**。
- 自有模板占位字仍有「产品经理 · 精臣生态」「NIIMBOT 牛肉三明治」——结构可算自研，文案不算。

RC 品牌最低交付：

1. 名称全部改为商跃标签。
2. 字母标改为「商」或「SY」，禁止 N / 精臣云标。
3. 启动引导、关于、隐私、帮助出现独立产品声明。
4. 主题色允许延后到公开商店前，但体验版对外邀请时建议已换，避免用户截图传播「假精臣」。

完整视觉系统（色板、图标、商店截图）是公开商店的 P0，不是内部硬件联调的 P0。

### 2.3 双端品牌关系

| 端 | 工程名 | 产品名 | 本轮 |
| --- | --- | --- | --- |
| 微信小程序 | `label-printer-miniapp` | 商跃标签 | **唯一 RC 载体** |
| Web / Capacitor | `niim-label-app` | 同一品牌，后期上架 | 不是 RC。代码审查：Web BLE 误写、批量截断删项目，未达候选 |
| 旧 Capacitor 子模块 | `label-printer-app` | 不对外 | 不出现在商跃货架 |

两端必须共用同一套来源分类和禁令。不允许 Web 写「精臣标签」、小程序写「商跃标签」。

## 3. 内容分类（硬边界）

来源以仓库里已经存在的 `source` 为准，不以后台展示名为准。改名、改行业、改「热门」徽章，**不改变来源**。

| 级别 | `source` / 证据 | 数量（当前仓库） | 法律身份 | 用户可见货架名 | 可否称商跃原创 | 对外 RC |
| --- | --- | --- | --- | --- | --- | --- |
| A1 商跃原创 | 显式 `origin: shangyue-original`，并有独立来源登记与洁净室说明 | 22 | 已完成工程来源登记；法律登记另行办理 | **商跃模板** | 可以 | **可以** |
| A2 精诚授权改编 | `origin: shangyue-authorized-redesign`（2026-09-28 起货架上没有此类，原 5 套已由权利人决定转入 A1） | 0 | 用户确认已获同意；书面商用范围仍须归档 | **授权改编** | 不可以 | **凭证齐备后可以** |
| A3 商跃场景模板 | `origin: shangyue-original`、`source: shangyue-curated`、逐套质量门与看图 | 300 套 | 商跃原创；48 个场景配方、每个配方多种版式，300 套版式各不相同，示例内容虚构 | **场景模板** | 可以 | **可以** |
| A0 内置候选 | 无第三方 `source`，但尚未补齐逐套来源登记的基础结构 | 32 | 待逐套权属审查，不能因 `!source` 自动视作原创 | 内部基础模板 | **暂不可以** | **暂不进入商跃货架** |
| B 用户作品 | `source: user`，以及用户主动导入的自有 JSON | 本地，模板 ≤ 80 | 用户所有 | **我的模板** | 否（属于用户） | **可以** |
| C 精臣导入包 | `source: niim-import`，`data/niim-templates/*.json` | 4 | 精臣来源 | 若内部可见：精臣参考 · 导入 | **禁止** | **禁止对外** |
| D 精臣固化包 | `source: online-niim`，`online-templates-pack.js`，blurb 已写「精臣线上行业模板」 | 153 | 精臣来源 | 若内部可见：精臣参考 · 固化 | **禁止** | **禁止对外** |
| E 精臣在线目录 | `source: remote-niim`，`print.niimbot.com` 分页 | 快照约 9,161 | 精臣来源 | 若未来有书面授权：精臣公开模板 | **禁止** | **禁止对外**（无书面授权） |
| F 精臣素材 / 边框远程 | `original-materials.json`、`remote-niim-material` / `remote-niim-border` | 144 随包图 + 远程 2,567 / 632 | 精臣来源 | 精臣素材 / 精臣边框 | **禁止** | **禁止对外** |
| G 商跃程序化边框 | 代码生成的 20 种几何边框 | 20 | 自有（若实现为几何描边、无精臣位图） | 商跃边框 | 可以 | **可以** |
| H 商跃矢量素材 | `material-symbols-v2.js`、`source: shangyue-vector-v2` | 76 | 独立路径规则；不引用图片、外部图标字体或精臣素材 | **商跃素材** | 可称商跃矢量素材 | **可以** |

当前对外口误风险最高的三处：

1. 首页 / 引导写「190 个商跃模板」——把 C+D 算进了商跃库存。
2. 导入包徽章为「官方」（`imported-templates.js`）——一旦应用改名，用户会读成「商跃官方」。
3. 在线记录 `badge: VIP`、`blurb: 授权在线行业模板`——仓库里**没有**授权编号、地域、有效期；`AUTHORIZED_CONTENT_LIBRARY.md` 已写明 manifest 授权字段仍是占位。在授权落盘前，「授权」二字不得出现在用户界面。

### 3.1 七条禁令

1. **禁止改名洗白。** 不得把 `价签-外套` 改成 `商跃外套价签` 后放入「商跃模板」。
2. **禁止混架。** 「商跃模板」货架只放级别 A。A0 在逐套过审前也不能进入；C/D/E/F 即使将来授权，也必须独立货架，标题带「精臣」或「第三方来源」。
3. **禁止去 VIP 转售。** 不得去掉 `vip` 当商跃免费赠品，也不得自建「商跃 VIP」卖精臣图。
4. **禁止用精臣图做商店截图、启动页、推荐位封面。**
5. **禁止把直连 `print.niimbot.com` + `AppVersionName/6.6.6` 写成「商跃内容服务」。** 那是精臣公共目录客户端。
6. **禁止在帮助里写「我们提供上万套行业模板」**，除非货架上能逐条指向已授权的精臣来源，并且用户看得见来源标记。
7. **来源一旦写入文档 / 项目，跟随副本一生。** 用户「另存为我的模板」后，来源仍是精臣来源；只是所有权变成「用户持有的一份副本」，不是「商跃原创」。

### 3.2 用户另存与导入

| 用户动作 | 结果归属 | 界面必须显示 |
| --- | --- | --- |
| 用商跃模板另存 | 我的模板，来源=商跃 | 可不再角标，或保留「基于商跃模板」 |
| 用精臣来源模板另存 | 我的模板，来源仍=精臣 | 「来源：精臣」一直可见 |
| 导入自有 JSON | 我的模板，来源=用户导入 | 「我导入的」 |
| 导入 NIIM / 精臣 JSON | 我的模板，来源=精臣 | 「来源：精臣（用户导入）」 |
| 空白画布保存 | 我的模板，来源=用户 | 无第三方角标 |

另存不能当洗白。

### 3.3 内部工程包 vs 对外货架

工程上可以暂时保留 190 套完整目录和在线客户端，方便对照打印和回归。产品上必须拆成两个开关：

| 开关（产品名） | 默认（对外 RC） | 谁能开 | 界面 |
| --- | --- | --- | --- |
| 商跃模板 | 开 | 全员 | 仅显式过审的原创模板（当前 22 套） |
| 内置候选库 | **关** | 仅内部审查 | 32 套基础结构，逐套补来源登记后才可迁入商跃货架 |
| 精臣参考库 | **关** | 仅内部构建 / 持有书面授权后的专项包 | 每条带「精臣」角标，分区隔离 |
| 精臣在线目录 | **关** | 同上，且必须换成自有镜像基址，禁止伪造官方 UA 长期直连 | 失败时只说「第三方目录不可用」，第三方数量不得写成商跃库存 |

内部包打开时，引导和关于页仍须写：这些是精臣来源参考模板，不是商跃作品。

## 4. 小程序 RC 范围

对照代码审查（2026-08-16）：小程序有条件 RC，Web 不是 RC。产品 RC 只讨论小程序。

### 4.1 RC 卖的闭环

```
首次引导（商跃，不提 189/精臣库）
  → 空白 / 扫码建标 / 商跃模板
  → 编辑（10 类元素，本地素材用几何/自有，不用精臣 PNG）
  → 打印预检（机型、尺寸、占位、编码）
  → BLE 连接（只认 NIIMBOT E781 通道）
  → 出纸
  → 项目 / 历史 / 我的模板 / JSON 备份
```

这就是 1.0.0-rc.1 对外可讲的产品。

### 4.2 RC 包含

- 品牌最低交付（第 2.2 节）。
- 22 套已登记商跃原创模板；另外 32 套基础结构只作为内部候选，逐套审查并登记后才可开放。
- 空白、耗材尺寸、Wi-Fi 码样例（样例里的 SSID/密码必须是虚构，且提示用户改掉）。
- 扫码建标 / 扫码填入（本期已定功能，见 `FEATURE_SPEC_SCAN_TO_LABEL.md`）。
- 我的标签、CSV 四字段批量（批量选择器列出 **32 个通用四字段兼容的内置基础模板**；兼容性不代表原创权属，祝福卡明确不参与商品字段批量绑定）。
- 本地项目 120、我的模板 80、历史 80、自动保存、schema v2、备份回滚。
- 打印预检 + D11 / D110 / B1 / B21 已实现 profile；候选映射 `2320`、`4098` 继续强制手确认；B21 Pro `D110M_V4` 明确不支持。
- 连接恢复、诊断不出纸、失败不自动重放。
- 20 个程序化边框。
- 帮助：蓝牙、权限、耗材、备份；写明独立产品与兼容机型。

### 4.3 RC 不包含（对外关闭）

- 153 固化精臣模板、4 套 NIIM 导入模板进入用户货架。
- 运行时请求 `print.niimbot.com` 与四个精臣 OSS 域名。
- 144 张精臣随包素材 PNG 作为「商跃素材库」展示。
- VIP 徽章、授权目录、上万套行业模板的任何营销句。
- 账号、云同步、支付、耗材电商、远程打印。
- Web / Android 商店发布。
- 把「域名白名单配好精臣 CDN」当作 RC 内容门禁——对外 RC **不依赖**这些域名。内部对照包另算。

这一条同时消掉审查报告 P2#8 对对外 RC 的阻塞：公开候选若不拉精臣目录，就不需要把 `print.niimbot.com` 配进生产合法域名。

### 4.4 RC 仍必须过的非内容门禁

内容收窄不等于可以跳过硬件和平台：

- 正式 AppID、类目、隐私指引（蓝牙、相册、相机扫码、文件）。
- 微信编译、包体、体验版。
- Android / iOS × D11 / D110 / B1 / B21 实物矩阵。
- 扫码权限真机。
- 远程图缓存淘汰：对外 RC 若不拉远程图，P2#7 降为内部包问题；一旦打开精臣参考库，必须先做 LRU。

### 4.5 对外数量口径

| 旧口径（工程文档） | RC 对外口径 |
| --- | --- |
| 190 个系统模板 | 当前 22 个已登记商跃原创模板；其余按来源或待审状态单独管理 |
| 144 个内置素材 | 不宣传精臣 PNG；可宣传「相册图片 + 商跃边框」 |
| 授权在线 9,161 | 不宣传 |
| 批量 32 个兼容基础模板 | 按实际字段绑定能力单列；不得把“兼容”写成“商跃原创” |

首页、引导、模板副标题、商店简介不得拿完整目录数量充当原创库存。硬编码总数是产品错误，不只是文案债。

### 4.6 RC 验收（产品）

对外体验版可以邀请用户，当且仅当：

1. 界面无「精臣标签」产品名、无 N 标、无「官方」徽章打在精臣包上。
2. 模板货架打开后，每一张可见卡片的来源 ∈ {商跃, 我的}。抽检 100% 卡片，0 张精臣包混入「商跃模板」。
3. 断网可完成：开模板 → 改字 → 预检（连机除外）。
4. 关于 / 帮助有独立产品声明和兼容机型列表。
5. 商店或体验版介绍不出现 189、上万套、VIP、授权精品。
6. 法务未签字前，构建开关「精臣参考库」「精臣在线目录」为关。

未满足 1–6，只能叫内部工程候选，不能叫商跃 RC。

## 5. 以后若要上精臣内容（非本轮）

只有同时满足才能打开第三方货架：

1. 书面授权：权利人、范围（模板 / 图 / 再分发 / 改图）、地域、期限、是否含 VIP、是否允许小程序分发。编号写入 `AUTHORIZED_CONTENT_LIBRARY.md`，占位字段作废。
2. 生产流量走**自有只读镜像**，不长期用精臣官方 UA 直连生产 API。
3. UI 独立分区，标题含「精臣」或「第三方」，每卡来源角标。
4. 不进入「商跃模板」「推荐（商跃）」默认位。
5. 用户另存仍保留来源。
6. 授权到期：货架下线，本地已打开的用户项目可继续编辑（已在用户设备上的副本），但不再提供缩略图热更新和新下载。

在此之前，任何「先上架再补授权」都是产品否决项。

## 7. 已定 vs 留给法务 / 发布

已定（产品，可执行）：

- 产品名商跃标签，独立品牌。
- RC 载体只有小程序。
- RC 货架只有商跃模板 + 我的模板。
- 精臣来源永不可称商跃原创。
- 无书面授权则无对外精臣库、无精臣 CDN 生产域名依赖。

默认假设（无反证前按此做）：

- 54 套 `baseTemplates` 中已有 22 套进入商跃过审库；另外 32 套留在候选库，发布前必须逐套清掉第三方占位字并补来源记录。
- 20 个程序化边框视为自有。
- 144 张 `original-materials` 视为精臣来源图，RC 不出素材馆。

必须法务签字后才能改口：

- 除已登记的 22 套 `shangyue-*` 洁净室模板外，其余 32 套是否有任何一页描摹第三方原版，仍需逐套确认后才能称原创。
- C–F 是否存在可引用的再分发许可。
- 微信名称是否与他人商标冲突。
