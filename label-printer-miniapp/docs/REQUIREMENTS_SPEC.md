# 精臣标签小程序软件需求规格说明书（SRS）

文档版本：1.0
需求基线日期：2026-08-11
文档状态：工程候选基线，未获生产放行

## 1. 文档目的

本文定义将 `niim-label-app` 的核心产品体验迁移为微信小程序时必须满足的可验证需求，作为产品、开发、测试、硬件和发布团队的共同验收基线。

需求中的“必须”表示发布阻断要求；“应”表示上线前应满足，若例外必须有责任人和书面风险接受。本文描述当前目标实现，不把 Node 模拟测试等同于微信真机或物理打印验证。

## 2. 背景、目标与范围

### 2.1 背景

目标用户需要在手机上完成标签模板选择、内容编辑、项目复用、数据批量生成、蓝牙连接和实体打印。原 Web 应用具备相应领域模型和交互参考，但微信小程序在页面生命周期、本地存储、Canvas、文件 API、BLE、包体和隐私审核方面存在不同约束，需要平台化迁移。

### 2.2 产品目标

- 形成“选择模板/耗材 → 编辑 → 打印预检 → 连接 → 打印 → 历史/复用”的本地闭环。
- 支持从现实商品码、资产码或二维码一次扫码创建标签，并可向已有编码元素扫码填入，减少手工录入错误。
- 离线提供 189 个系统模板，并支持用户本地模板和项目。
- 在编辑器中支持文本、图片、素材、日期、条码、二维码、序列号、矩形、表格、线条 10 类元素。
- 对支持的 NIIMBOT/精臣打印机执行安全的 BLE 协议握手和打印，阻止错误机型、尺寸、占位内容或无效编码进入发送阶段。
- 以本地优先和最少数据处理为原则，不要求登录或云服务。

### 2.3 当前系统边界

小程序当前由两个微信 Page 构成：

- `pages/home/index`：承载首页、模板、我的标签、批量数据、我的五个壳内视图。
- `pages/editor/index`：承载标签画布、元素属性、图层、设置、设备连接、预检和打印。

领域核心、模板目录、仓储、BLE 会话、连接管理和打印客户端均位于小程序包内。除用户主动选择/分享文件、访问相册及使用 BLE 外，核心编辑和浏览不依赖网络服务。

## 4. 假设与约束

### 4.1 假设

- 用户持有微信支持的 Android 或 iOS 手机，并主动授予任务所需权限。
- 打印机处于支持列表、开机、在 BLE 范围内，固件与已实现 profile 相符。
- 标签纸尺寸和类型由用户正确安装并在预检中确认。
- 微信本地存储仍有足够容量保存文档和数据；图片以微信可访问的本地路径存在。
- 生产发布前可以获得正式 AppID、合法主体、适用服务类目及品牌/内容授权。

### 4.2 技术与产品约束

- 当前 `project.config.json` 仍使用 `touristappid`；在替换为正式 AppID 前不能完成正式预览、上传、审核或发布。
- 当前数据为本地 schema v2，无账号、云同步或跨设备一致性。
- 系统模板固定为 189 个；编辑器素材目录为 144 个，装饰边框为 20 种。
- 批量页面当前只在选择器中暴露系统目录前 32 个模板，作为当前批量兼容集；不能在 UI 中暗示全部 189 个均可直接批量选择。
- 小程序使用 E781 服务与 NIIMBOT `0x55` 帧协议。FF00/FF02/FF03 ESC/POS credit 令牌流控属于不同协议，不得混接。
- 打印机能力与编辑文档分离：用户可以编辑当前机型无法打印的尺寸，但发送前必须阻断，不能静默裁切或覆盖原文档。
- 微信平台限制以发布当日官方规则为准；内部主包目标为不超过适用上限的 90%。

## 7. 明确不在当前范围

- 账号体系、手机号登录、会员、付费素材或订阅。
- 云同步、多人协作、跨手机实时同步和 Web 后台。
- 电商耗材购买、订单、支付、发票和物流。
- 远程/互联网打印、打印队列服务和服务器端渲染。
- 非 NIIMBOT 协议打印机、经典蓝牙、USB、Wi-Fi 打印和 ESC/POS FF00 credit 协议。
- 在小程序内升级打印机固件、修改硬件参数或自动识别所有未知型号。
- 在生产环境上传标签内容或建立内容画像。
- 未经授权使用精臣/NIIMBOT 品牌、模板、缩略图和素材；代码完成不构成授权。

## 8. 验收与追踪

### 8.1 工程验收

- 所有 FR 对应的自动化和静态测试通过，189 模板和 10 类元素全量验证。
- 干净依赖安装、构建和微信开发者工具编译通过；包体达到 NFR-PKG-001。
- 首页五视图和编辑器无失效事件、不可关闭模态层或无反馈写操作。
- schema 迁移、批量保存、恢复回滚和打印历史边界有故障注入证据。

### 8.2 平台与硬件验收

- 使用正式 AppID 完成开发者工具编译、预览、体验版和真机调试。
- Android/iOS × D11/D110/B1/B21 系列规定矩阵完成首次连接、复连、蓝牙开关、僵尸恢复、断线和实物打印。
- 40×12、40×30 及打印头边界样张方向和尺寸正确；条码/二维码可扫，份数、纸型和序列号正确。
- 真机失败必须关联系统、微信、打印机、固件、耗材、profile、MTU 和阶段证据。

### 8.3 产品验收

- 新用户首次任务和回访重打达到 NFR-USE-001。
- 权限拒绝、无设备、无项目、无模板结果、CSV 错误、存储不足、打印中断均可恢复。
- 用户明确理解数据在本机、备份会覆盖、失败打印不会自动重放。
