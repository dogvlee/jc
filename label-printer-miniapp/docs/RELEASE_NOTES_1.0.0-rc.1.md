# 1.0.0-rc.1 版本说明

候选记录日期：2026-08-11
发布类型：工程候选版
当前结论：冻结提交的本地门禁待最终归档，生产发布 No-go

## 主要能力

- 完成首页、模板、我的标签、批量数据、我的和 Canvas 编辑器的微信原生实现。
- 内置 189 套离线模板、144 个黑白素材、20 种边框和六种文字方向。
- 支持文字、图片、素材、日期、条码、二维码、序列号、形状、表格、线条十类元素。
- 支持移动、缩放、旋转、吸附、多选、对齐、分布、锁定、镜像、图层与撤销/重做。
- 支持项目、用户模板、自动保存、打印历史、CSV 批量生成和 JSON 备份恢复。
- 支持首页扫码建标和编辑器扫码填入：按一维码/二维码创建或更新编码元素，取消、失败和类型不匹配不改原稿。
- 支持非破坏式打印预检以及 D11、D110、B1、B21 相关打印任务族。
- 引入应用级 BLE 连接管理：单飞、TTL、系统连接复用、`already connect`、僵尸连接恢复、蓝牙恢复自动复连、诊断和 kill switch。

## 数据变化

- 本地仓储版本升级为 schema v2。
- 首次运行会迁移旧编辑器文档、用户模板和默认打印机 profile。
- 项目最多 120 个，用户模板最多 80 个，批量数据最多 1000 行，打印历史最多 80 条；最近 10 条历史保留可重新打开的文档快照。
- JSON 恢复先完成验证，并在中途写入失败时尝试恢复原有数据。

## 验证证据

- 冻结候选提交必须执行 `npm run verify`；测试数、文件数、事件绑定、资源引用和本地主包字节以该次完整输出为准。
- 同一提交执行 `npm run test:coverage`，行/分支/函数覆盖率以最新输出为准，不沿用开发过程快照。
- 本地主包结果只作预警；最终包体以微信开发者工具上传报告为准。

上述证据不包含微信开发者工具编译、WXML 真实交互、Canvas 真机差异或物理打印结果。

## 已知限制

- `project.config.json` 仍为 `touristappid`，尚未完成正式 AppID 编译和上传。
- 尚未执行 Android/iOS × D11/D110/B1/B21 的完整真机矩阵。
- 相机扫码的 Android/iOS 授权、取消、拒绝/恢复及实物码结果尚未完成真机验收。
- `2320 → d110`、`4098 → b1` 是候选映射；B21 Pro `D110M_V4` 未适配。
- 只支持 BLE，不支持经典蓝牙 SPP。
- 当前为本地数据模式，不含账号、云同步、团队协作和远程模板服务。
- 素材和模板对外发布前需要完成品牌与再分发授权确认。

## 升级与回滚

- 升级前建议导出 JSON 备份。
- schema v2 迁移会清理已迁移的旧键；回退旧版本前必须验证旧版本能否识别当前数据。
- 若灰度发现 P0 问题，应停止放量、关闭相关能力或下架候选版本，并依据备份进行数据恢复。
- BLE 故障可通过 `ble_reconnect_off` kill switch 禁用自动复连，但不会删除已保存设备。

生产放行条件与责任签署见 [RELEASE_CHECKLIST.md](./RELEASE_CHECKLIST.md)。
