# 精臣标签小程序体验与交互规格

文档版本：1.0
基线日期：2026-08-11
文档状态：候选体验规格，待微信真机与用户测试

## 1. 体验目标与原则

目标体验不是把桌面编辑器压缩进手机，而是让用户随时知道“我在编辑什么、是否能打印、打印到了哪一步、失败后该做什么”。

设计原则：

1. 任务优先：新建、模板、最近项目和打印是首层动作，专业属性按选中元素渐进呈现。
2. 本地可信：清楚说明数据默认只在本机，删除、恢复覆盖和打印中断不使用含糊成功文案。
3. 先预检后出纸：尺寸、机型、占位内容和编码错误在发送前处理，避免浪费耗材。
4. 状态可见：连接和打印使用“文字 + 图形 + 状态变化”，不能只显示一个蓝牙图标或颜色点。
5. 可恢复：页面切走、蓝牙关闭、假连接、存储失败或打印中断都有下一步；不把“清空微信数据”作为常规方案。
6. 保留用户意图：切换打印机不改变文档尺寸，失败不自动重放可能已经打印的内容。

```

│  ├─ 搜索 / 分类 / 行业 / 我的
```

## 3. 核心旅程与状态模型

### 3.1 首次使用

| 阶段 | 界面 | 主动作 | 退出/恢复 |
| --- | --- | --- | --- |
| 首次进入 | 三页引导卡 | 下一步 / 开始使用 | 可跳过；结果持久化 |
| 连接打印机 | 引导第 1 页仅解释，不强制连接 | 下一步 | 未连接仍可模板/编辑 |
| 选择模板 | 引导第 2 页说明 189 个离线模板 | 下一步 | 可从空白开始 |
| 编辑并打印 | 引导第 3 页说明本地保存与预检 | 开始使用 | 进入首页，不自动出纸 |

引导不得把连接打印机作为编辑前置条件。首次权限只在用户点“连接设备”“扫码建标/扫描填入”“选择图片”或“导入文件”时请求，不在冷启动集中索取。

### 3.2 从模板到打印

1. 用户从首页快捷项或“模板”进入，筛选并打开预览。
2. 预览展示真实尺寸和元素摘要；点击“使用此模板”后克隆到编辑器。
3. 编辑器先显示标签本身，再根据点选元素显示属性。空白/默认内容保留可见占位，但在打印预检阻断。
4. 用户点击“打印”，底部 Sheet 展示设备、profile、纸型、浓度/阈值和份数。
5. 如有阻断，主按钮禁用，警示卡给出单一修复方向；如缺设备，动作显示“连接并打印”。
6. 连接确认后进入点阵生成与发送进度；成功写历史，失败说明不会自动重放并保留手动重打决定。

### 3.3 最近项目重打

1. 首页最近编辑显示最多 4 项；用户点项目进入编辑器。
2. 编辑器恢复文档和项目 ID，用户可直接打印或修改后保存。
3. 打印历史最多展示 20 条；最近 10 条有标签副本可“打开”，更早记录明确显示“仅记录”。

目标：回访用户从首页到进入打印预检不超过 30 秒，不要求重新选择模板。

### 3.4 批量生成

1. 批量页使用横向可滚动表格编辑名称、编码/条码、价格、日期。
2. 导入 CSV 后反馈实际行数；解析失败保留原表格。
3. 用户从当前 32 个兼容模板中选择，主按钮显示“生成 N 个标签”。其中 N 应以非空有效行数为准；当前界面使用数据行总数，发布前需用可用性测试确认是否造成误解。
4. 提交时逐行校验；首个错误显示“第 N 行无法生成”和具体原因，整批不写入。
5. 成功显示实际生成数并打开第一个项目；其他项目可在“我的标签”找到。

### 3.5 连接与中断恢复

连接状态机：

```
未连接 → 扫描中 → 发现设备 → 连接中 → 已连接
   ↑          │          │          │         │
   └─ 无结果 ┘          └─ 失败 ───┘         └─ 物理断线 → 恢复中/未连接
```

- “扫描中”显示动态文字“正在搜索附近蓝牙设备…”，列表仍可逐步出现。
- “无结果”提示打开打印机并靠近手机，扫描结束后提供关闭再重扫的路径。
- “连接中”禁用设备重复点击；关闭 Sheet 不应造成多个并发连接。
- “已连接”展示设备名和 MTU/协议等详情，提供断开、诊断和忘记设备。
- 物理断线立即撤销“已连接”状态；自动恢复期间使用“连接中/正在恢复”，不能保持绿色状态。
- 用户主动断开与忘记设备后不自动连回；系统蓝牙重新开启时可恢复已保存设备。
- 诊断结果分适配器、系统连接、GATT、打印协议、MTU、型号 ID 和连接路径，必须注明诊断不会打印。

### 3.6 打印状态机

```
空闲 → 预检
       ├─ 阻断 → 修复 → 再预检
       └─ 通过 → 确认连接 → 生成点阵 → 发送/进度
                                      ├─ 完成
                                      ├─ 取消后续发送
                                      └─ 失败（不自动重放）
```

- 预检 Sheet 可关闭；打印中关闭请求应提示“正在打印，请先取消或等待完成”。
- 进度至少区分“确认打印机连接”“生成打印点阵”和协议发送阶段。
- 用户点取消后显示“正在停止打印…”，最终状态为“打印已取消”；不得声称纸面内容已撤回。
- 失败卡固定包含：“为避免重复或半张标签，系统不会自动重放整单，请检查实物后手动重打。”

### 3.7 扫码建标

1. 用户从首页“扫码建标”主动进入微信原生扫码界面。
2. 扫到一维码时创建条码标签；扫到二维码时创建二维码标签。成功后直接进入可编辑画布，不自动打印。
3. 编辑已有设计时，只有选中条码/二维码才显示“扫描填入”；请求类型与元素一致，避免二维码内容静默写入一维码。
4. 用户取消后原页面和原元素保持不变，不显示失败 Toast；权限或平台失败时说明检查权限或升级微信。
5. 扫码内容仍需经过格式和打印预检，成功扫描不等于内容一定能在当前尺寸安全打印。

## 4. 页面与交互规范

### 4.1 首页

- 顶部红色 Hero 内放品牌、帮助和设备胶囊；连接成功显示设备名，未连接显示“未连接”。设备胶囊为全局连接入口。
- 第一屏四个快捷入口使用相同点击面积和“图形 + 文本”，不能只靠抽象符号表达。
- Wi-Fi 横幅必须说明结果是扫码联网标签；点击直接创建 `wifi-code` 模板文档。
- 耗材卡同时显示默认尺寸的文本和纸张示意，“换纸”与“新建”分工明确。
- 最近编辑为空时显示“还没有编辑过标签”，主动作“新建标签”；有内容时卡片至少包含名称、尺寸和更新时间。
- 推荐模板卡片的整个区域可点击；缩略图缺失时使用抽象预览。
- 快捷创建提供空白、扫码建标、批量、连接设备；恢复备份继续保留在“我的”。所有入口均不得在点击后无反馈。

### 4.2 模板

- 顶栏显示筛选后总数与当前显示数；右侧“导入模板”选择 `.json`。
- 搜索框文案为“搜索模板名称、行业、用途”，输入后即时筛选并将展示数重置为 24。
- 分类和行业采用横向滚动 Chip；已选项必须同时有形状/文字状态，避免只用颜色。
- 模板卡展示缩略图、名称、尺寸、分类和简介；点击进入底部预览，不直接替换当前项目。
- 预览底部主动作“使用此模板”；用户模板额外显示危险动作“删除”。系统模板不得出现删除。
- 无结果文案：“没有找到匹配模板 / 换个关键词，或恢复全部筛选”，动作“恢复全部”。

### 4.3 我的标签

- 顶栏显示当前筛选结果数量和“新建”；搜索占位“搜索标签名称”。
- 项目卡主区域打开编辑，删除为独立动作并提供 `aria-label`；不得让删除点击冒泡为打开。
- 删除确认必须包含项目名及不可撤销含义。成功后列表即时刷新；失败必须提示，不能静默消失。
- 空状态文案：“还没有保存的标签 / 编辑器中的‘保存’会把标签放到这里”，动作“创建第一个标签”。

### 4.4 批量数据

- 工具栏把“导入 CSV”和“导出 CSV”并列；添加行放在页头，避免与整批生成混淆。
- 表头固定语义为名称、编码/条码、价格、日期；小屏允许横向滚动，不压缩到无法输入。
- 单元格离焦保存。删除行必须有足够点击区；当仅剩一行或空表时仍显示“添加行”。
- 批量卡说明“会为每一行创建一个可继续编辑的本地标签”，模板选择后显示当前模板名。
- 提交期间按钮防重复并显示处理中状态；当前代码为同步构建，超过感知阈值时需要增加进度/分片。

### 4.5 我的

- 明确标题“本地模式”和“无需登录，数据只保存在当前设备”。
- 三个统计为我的标签、我的模板、打印记录；标签数量必须使用完整项目数而非当前搜索结果。
- 菜单按设备/设置/历史、备份、帮助分组；备份动作使用“导出备份”“恢复备份”而非方向不明的“同步”。
- 页底隐私说明必须与真实权限一致。当前相机用途为用户主动触发的扫码，相册用于选择图片，消息文件用于 CSV/JSON，蓝牙用于连接打印机；正式隐私保护指引必须逐项对应。

### 4.6 编辑器布局

- 顶栏图标顺序固定：关闭、撤销、重做；右侧图层、打印机、设置。纯图标按钮必须有可访问名称。
- 文档行支持名称编辑，右侧显示 `宽×高 mm` 和连接状态。连接状态不能只用圆点；屏幕阅读器名称或相邻文字必须可读。
- Canvas 置于可滚动画布舞台，保持标签比例。准备期间显示“正在准备标签画布…”。
- 底部面板三 Tab：添加元素、模板、数据源。保存与打印为始终可见的固定底部动作，并避开安全区。
- “模板”Tab 只管理我的模板，并明确系统 189 套模板从首页进入；“数据源”Tab 引导返回首页批量页，不伪装为内嵌数据编辑。

### 4.7 Canvas 手势与选择

- 点击选中最上层命中元素；选中框、缩放柄和旋转柄必须与旋转后的可视边界一致。
- 单选拖动移动，右侧/边缘柄缩放，右下柄旋转；操作提示随锁定、多选状态变化。
- 锁定元素可以选中查看，但拖动/批量编排不得改变它。
- 长按另一个元素扩展选择；多选模式下点击未选元素继续加入。显式“完成”退出多选。
- 多选提供左/水平中/右、上/垂直中/下六向对齐；三个及以上未锁定元素才允许均匀分布。
- 吸附线只在接近可吸附位置时出现，手势结束立即消失；不长期覆盖打印内容。
- 删除、清空和替换操作必须能撤销或二次确认。当前项目删除/清空有确认，元素删除主要依赖撤销；可用性测试需确认误触率。

### 4.8 元素属性呈现

- 未选中时只显示“点击上方元素添加到标签”；选中单个时按类型展示专属属性和通用位置/尺寸。
- 10 个添加按钮顺序与当前代码一致：文本、图片、素材、时间、条码、二维码、序列号、形状、表格、线条。
- 文本/日期/序列/表格共用文字样式区，减少重复；条码/二维码先显示内容与制式；图片/素材先显示替换动作。
- 条码/二维码属性区在内容输入下方提供“扫描填入”；取消和失败不收起当前上下文或修改原值。
- 数值字段统一标注单位 mm 或 °；越界输入在离焦后立即提示并恢复有效值，不能只在打印时才暴露。
- 多选时隐藏单元素内容属性，仅显示编排工具，避免用户误以为一次可批改异构元素内容。

### 4.9 Bottom Sheet 与模态层

- Sheet 顶部含拖拽柄、标题、可选说明和明确关闭按钮；点击遮罩可关闭的 Sheet 在高风险/进行中状态例外。
- 键盘出现时输入字段和确认动作必须可滚动到可见区域。
- 删除项目/模板、清空画布、覆盖恢复使用系统确认框；确认文案陈述对象和后果，危险确认色统一。
- 同一时间只允许一个顶层 Sheet；打开设备、打印或设置时先关闭冲突面板。

## 5. 状态、空态、错误与权限

| 场景 | 当前/目标文案 | 主动作 | 恢复规则 |
| --- | --- | --- | --- |
| Canvas 加载 | 正在准备标签画布… | 无，禁用打印 | 成功后自动消失；失败显示原因与重试 |
| 无项目 | 还没有保存的标签 | 创建第一个标签 | 新建空白文档 |
| 模板无结果 | 没有找到匹配模板 | 恢复全部 | 清空搜索和筛选 |
| 无打印历史 | 暂无打印记录 | 无强制动作 | 完成/失败打印后出现 |
| 数据为空 | 还没有批量数据 | 添加一行 / 导入 CSV | 不允许“生成 0 个标签” |
| 蓝牙关闭 | 蓝牙未开启，请在系统设置中打开后重试 | 我已打开，重新扫描 | 保留草稿，不要求重启小程序 |
| 蓝牙权限拒绝 | 需要蓝牙权限才能查找打印机；你仍可继续编辑 | 打开设置 / 暂不连接 | 返回后重新检测，不循环弹窗 |
| 相册权限拒绝 | 未获得相册权限，未添加图片 | 打开设置 / 取消 | 文档和原图片元素不变 |
| 扫码取消 | 不显示失败文案 | 无 | 留在原页面，文档和撤销栈不变 |
| 相机/扫码失败 | 扫码失败，请检查相机权限后重试 | 重试 / 返回 | 不创建标签、不修改原元素 |
| 扫码类型不匹配 | 当前选中的是一维码，请扫描商品条码；二维码内容请放入二维码元素 | 重新扫描 / 取消 | 原值不变 |
| 文件选择取消 | 未导入任何文件 | 无 Toast 或轻提示 | 原数据不变 |
| 无设备 | 没有发现打印机，请确认已开机并靠近手机 | 重新扫描 | 清理旧扫描结果 |
| 握手失败 | 连接到蓝牙，但未识别为受支持的打印机 | 选择其他设备 / 诊断 | 不发送打印数据 |
| 机型未知 | 请先确认准确的打印机型号，再开始打印 | 选择机型 | 不自动猜测后打印 |
| 空画布 | 请先添加至少一个标签元素 | 返回编辑 | 预检按钮禁用 |
| 默认占位 | 请先编辑文字/条码/二维码内容，当前仍是默认值 | 返回对应元素 | 聚焦问题元素为后续优化 |
| 尺寸不兼容 | 标签仍可编辑，但当前机型无法打印该尺寸 | 切换建议机型 / 调整尺寸 | 不裁切、不改写原文档 |
| 存储不足 | 本地存储空间不足，请先备份并删除不再使用的标签 | 导出备份 | 不显示保存成功 |
| 备份过新 | 备份版本过新，请升级小程序后再恢复 | 知道了 | 原数据不变 |
| 恢复写入失败 | 恢复未完成，原有本地数据已保留 | 重试 / 联系支持 | 已执行回滚 |
| 打印断线 | 打印机连接已断开，请靠近后重新连接再试 | 重新连接 | 检查实物后由用户决定重打 |
| 打印超时 | 打印机没有响应，请检查电源与纸仓后重试 | 诊断 / 手动重打 | 不自动整单重放 |
| 打印取消 | 打印已取消 | 关闭 / 检查实物 | 历史记录 cancelled |

错误文案结构统一为：发生了什么 → 当前数据/纸面是否安全 → 用户下一步。避免“操作失败”“错误 -1”这类无行动信息；底层错误码保留在脱敏诊断证据中，不直接替代用户文案。

## 6. 小屏、键盘与生命周期中断

### 6.1 小屏与安全区

- 所有顶栏使用 `safeArea.top`/状态栏高度，底部导航和编辑动作避开 `env(safe-area-inset-bottom)`。
- 320–375 CSS px 宽度下：模板卡保持可读；批量表格横向滚动；属性四列字段可降为两列；按钮文字不能裁成不可辨识单字。
- Bottom Sheet 最大高度应留出关闭按钮和安全区，内容使用内部纵向滚动。
- Canvas 最小舞台高度不能挤掉固定保存/打印；极端长标签允许舞台滚动查看，不扩大到覆盖面板。

### 6.2 键盘

- 文档名、文本、编码、表格单元格和数值输入获得焦点时，当前字段必须保持在键盘上方。
- 离焦触发保存/校验前保留用户原始输入；非法值说明原因并聚焦可修复字段。
- 键盘收起后恢复 Canvas/面板布局，不留下永久空白或被遮挡按钮。

### 6.3 页面切换和进程中断

- 当前实现会在编辑提交、手势结束、撤销/重做、保存和关闭新文档时更新自动草稿；`onHide` 只停止扫描，不关闭全局 BLE。中断测试必须覆盖尚未离焦的输入，若发现丢失则在隐藏前补交输入或保存，不得在规格中假定已经持久化。
- 微信回收进程后，从 `editorAutosave`/`editorDraft` 恢复文档；若草稿损坏，回到首页并提示，不打开空白替代原内容。
- 文件选择、系统设置、相册或权限面板返回时，恢复用户之前的 Sheet/编辑上下文。
- 打印中切后台必须保持任务状态或明确标记结果未知；不得在重新进入后直接显示成功。
- 来电、锁屏、蓝牙关闭等中断纳入 Android/iOS 真机旅程。

## 7. 可访问性规范

- 图标按钮必须提供中文可访问名称；当前关闭、撤销、重做、图层、打印机、设置、帮助、新建和删除已有部分 `aria-label`，其余需补齐并真机读屏验证。
- 主导航、连接状态、选中数量、打印进度和阻断原因必须可由读屏软件读出；动态状态变更应有适度播报，避免每个进度百分比连续打断。
- 交互目标建议不小于 44×44 CSS px，目标间至少留出 8 px；当前部分 70rpx 图标按钮需在目标设备测量，不能仅按设计稿推断合格。
- 正文与背景对比度目标 ≥ 4.5:1，大号文字 ≥ 3:1；连接成功/失败、历史成功/失败不能只用绿/红区分。
- 支持系统字体放大后完成首页→模板→编辑→预检的主流程；不强制横屏，不依赖双指复杂手势。
- 每个输入有可见标签或明确上下文；`X/Y/宽/高` 等缩写需通过“位置与尺寸 / mm”组标题补充语义。
- 动画遵循系统减少动态效果偏好；连接/打印进度不使用高频闪烁。

## 8. 关键文案规范

| 用途 | 推荐文案 | 避免 |
| --- | --- | --- |
| 本地模式 | 无需登录，数据只保存在当前设备 | 数据绝对不会丢失 |
| 保存成功 | 已保存到“我的标签” | 操作成功 |
| 批量成功 | 已生成 24 个标签 | 批量处理成功 |
| 删除项目 | 确定删除“{名称}”吗？此操作不可撤销。 | 是否删除？ |
| 恢复覆盖 | 恢复会覆盖本机现有项目、模板、数据和设置 | 是否导入？ |
| 未连接打印 | 连接并打印 | 立即打印 |
| 打印阻断 | 请先确认准确的打印机型号，再开始打印 | 参数错误 |
| 断线 | 打印机连接已断开，请靠近后重新连接再试 | BLE Error |
| 可能部分打印 | 系统不会自动重放整单，请检查实物后手动重打 | 已安全取消 |
| 诊断通过 | 连接诊断通过（不会打印） | 打印机完全正常 |

文案使用用户认识的对象（标签、打印机、纸张）而非内部概念（GATT、profile、task）。连接诊断详情可显示 GATT/MTU，但先给出普通语言结论。

建议北极星与护栏：

- 首次价值：首次启动后 3 分钟内进入打印预检的比例。

- 护栏：存储失败率、重复打印投诉、备份恢复失败、权限拒绝后的退出率。

指标不能证明物理纸面正确；真机样张和客服问题仍是必要证据。

## 10. 可用性测试计划

### 10.1 样本与设备

- 8–12 名参与者：小店经营者 3、仓储/办公 2、家庭用户 2、高级标签用户 2，另安排 1–3 名客服/QA 观察诊断任务。
- 至少一台小屏低端 Android、一台主流 Android、一台 iPhone；D110 与 B1 为最低实物测试，另按目标市场加入 D11/B21。
- 参与者使用无敏感内容的测试数据；研究人员记录成功、错误、回退、耗时和主观信心。

### 10.2 任务

1. 首次进入，不看说明，使用模板制作一张含中文和二维码的标签并进入预检。
2. 发现尺寸不适配当前打印机后，在不丢失内容的情况下修复。
3. 连接打印机、打印 1 张、断开再恢复连接。
4. 保存项目，回首页后从最近编辑重开并打印 3 份。
5. 导入含 5 行数据的 CSV，其中一行条码无效；找出问题并完成生成。
6. 导出备份，解释恢复操作会覆盖什么；取消后确认数据未变。
7. 模拟打印中断，解释系统当前状态并选择是否手动重打。
8. 客服/QA 运行连接诊断，判断故障位于蓝牙、链路还是协议。
9. 扫描一个商品条码生成标签，再在已有二维码元素中扫描填入；分别尝试取消和拒绝权限，确认原稿保留。

### 10.3 通过标准

- 至少 80% 首次用户在 3 分钟内无协助进入预检；100% 能在轻提示后完成。
- 至少 90% 回访任务在 30 秒内进入重打预检。
- 100% 参与者能识别“恢复会覆盖本机数据”和“失败不会自动重放”。
- 连接、打印、批量和备份任务无 P0 错误；每个任务首次尝试成功率 ≥ 85%。
- 小屏、键盘、读屏和系统大字体不使主要动作不可达。
- 对同一控件出现 3 次以上相同误解视为设计问题，不以“培训用户”关闭。

### 10.4 观察问题

- 用户是否理解“项目”“模板”“批量生成”的区别。
- 首页设备胶囊是否被认为是手机蓝牙总开关。
- 预检阻断能否定位到具体元素/尺寸；建议切换机型是否会被误解为已连接该机型。
- 长按多选、右侧缩放、右下旋转能否自然发现；是否需要首次手势提示。
- “取消打印”是否被误解为纸面一定未打印。
- 用户能否找到导出备份，以及是否理解数据仅存在当前微信设备。
