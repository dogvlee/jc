# 商跃标签 — 主路径体验（已拍板）

文档状态：Lead 已拍板，覆盖 `UX_SPEC.md` 第 2 节信息架构  
日期：2026-08-16  
作者：产品经理  
约束：只改产品文档，不改业务代码。模板归属仍遵守 `SHANGYUE_PRODUCT_DEFINITION.md`。

旧底栏是「首页 / 模板 / ＋ / 批量 / 我的」，「我的标签」藏在首页「全部」。下面是对外 RC 的主路径。

---

## 1. 底栏

五项，从左到右：

| 项 | 进哪 | 说明 |
| --- | --- | --- |
| 首页 | 回访与当前纸张 | 默认落地页 |
| 模板 | 商跃模板 + 我的模板 | 不进精臣库 |
| ＋ | 新建空白标签，进编辑器 | 中央主按钮；尺寸用「当前纸张」 |
| 标签 | 我的标签（原项目列表） | 升为底栏一级，不再只从首页「全部」钻 |
| 我的 | 设置、打印机、批量、备份、关于 | 批量从底栏拿掉，改放这里 |

批量不再占底栏。中央「＋」只新建，不打开批量。

```
首页壳
├─ 首页
├─ 模板
├─ ＋ → 编辑器（独立页）
├─ 标签
└─ 我的
     └─ 批量制标（二级）
```

编辑器仍是独立页，关闭后回到进入前的壳内视图。

---

## 2. 首页（首屏从上到下）

品牌区：商跃标签。不用「精臣标签」、不用 N 标。

首屏只留三块，顺序固定：

1. **最近标签**  
   回访第一动作。有项目则直接打开上次那张；「全部」进底栏「标签」。空状态：一句话 +「去选模板」或「新建」。
2. **当前纸张**  
   原耗材条改名「当前纸张」。展示宽×高；「换纸」改默认尺寸；「新建」与底栏「＋」同一行为。
3. **商跃模板**  
   只放级别 A 自有种子，4～6 张。点进预览再「使用」。标题就叫「商跃模板」，不叫「推荐模板」「行业模板」。

离开首屏（可放首页更下方，或只留在模板 / 我的，但不得占首屏）：

- Wi-Fi 码入口
- 行业模板大入口（现首页快捷四宫格里的「行业模板」）
- 打印历史（可从最近标签旁的次要文字链进「我的」）

扫码建标保留，但不跟 Wi-Fi / 行业模板抢首屏主位：放在最近标签空状态、或首页更下方的次要动作、或「＋」的补充，实现时不得插到「最近标签」上面。

---

## 3. 模板页

只两个货架：

| 货架 | 内容 |
| --- | --- |
| 商跃模板 | 确认自有的种子版式 |
| 我的模板 | 用户保存 / 用户导入 |

关掉、且不得在筛选或空状态里再提到：

- 授权在线目录
- 「189 个离线模板」
- 「官方」徽章
- VIP
- 精臣固化包、NIIM 导入包

搜索只打这两个货架。无结果：清筛选，不要推荐精臣在线。导入入口可留，导入精臣 JSON 必须标「来源：精臣」，不得进「商跃模板」。

---

## 4. 编辑器

- **打印**按钮保持显眼：底部主按钮，不被次要工具挤掉。
- 点打印仍先预检，再连机、再出纸。不改预检规则。
- 设备文案改成「热敏打印机」：连接按钮、状态条、预检设备行、空设备提示。
- 禁用：「你的精臣打印机」「精臣打印机已连接」「连接精臣」。
- 机型名（D11 / D110 / B1 / B21）和协议事实可出现在预检详情，那是硬件名，不是品牌冒充。

---

## 5. 我的

- 关于：独立产品声明。商跃标签与精臣无隶属或代理关系；兼容已测热敏机；数据默认本机。
- 批量制标从这里进：四字段表、CSV、选**商跃**兼容模板生成。不暗示精臣 189 包可批。
- 其余不变：默认机型 / 浓度 / 纸张、打印历史、备份恢复、帮助、连接与诊断。
- 帮助里的设备用语与编辑器一致：热敏打印机。

## 6. 实现对照（给改 UI 的同学）

| 现状（工程） | 拍板后 |
| --- | --- |
| 底栏：首页 / 模板 / ＋ / 批量 / 我的 | 首页 / 模板 / ＋ / 标签 / 我的 |
| 我的标签不是底栏项 | 「标签」是底栏项 |
| 首页先快捷模板四宫格、Wi-Fi 横幅、再耗材、再最近 | 先最近标签，再当前纸张，再商跃模板 4～6 张 |
| 模板页合并 189 + 远程目录 | 只商跃 + 我的 |
| 设备文案带精臣 | 热敏打印机 |
| 关于沿用精臣产品口吻 | 独立产品声明 |
