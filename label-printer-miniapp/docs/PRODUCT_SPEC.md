# 精臣标签小程序产品规格

文档状态：实施基线
版本：1.0
更新日期：2026-08-11

## 1. 产品目标与边界

本项目把 `niim-label-app` 的标签设计、模板、数据批量处理、项目管理和 NIIMBOT BLE 打印能力迁移到微信小程序，目标是在手机端形成“选耗材/模板 → 编辑 → 连接打印机 → 打印 → 留存复用”的本地闭环。

这里的“复刻”指功能、信息架构、核心交互和打印结果对齐，不代表可以未经许可使用 NIIMBOT/精臣商标、原应用素材或线上内容。品牌、素材和模板的再分发授权是发布前独立的 P0 合规门禁。

本版本采用本地优先设计：标签、项目、模板、批量数据、打印历史和设备绑定保存在微信本地存储；当前不包含账号、云同步、多人协作、支付、电商耗材购买或远程打印。

### 成功标准

- 新用户能在 3 分钟内从空白标签、模板或扫码结果完成首次编辑并进入打印预检。
- 回访用户能在 30 秒内从“最近标签”再次打印。
- 模板库可发现、预览和使用全部 189 个系统模板，且不会把系统模板全集写入本地存储。
- 编辑器支持 10 类元素：文本、条码、二维码、图片、矩形、线条、日期、序列号、表格、素材。
- 不兼容的标签尺寸或无法确认的机型必须在发送打印数据前阻断，而不是静默裁切。
- 蓝牙断开、系统“假连接”、蓝牙开关切换和小程序进程重启均有可理解的恢复路径。
- 所有 P0 自动化、微信开发者工具编译、隐私/合规和规定真机矩阵通过后才允许生产发布。

## 2. 目标用户与 JTBD

| 角色 | 场景 | 核心 JTBD | 成功信号 |
| --- | --- | --- | --- |
| 小店经营者 | 商品价签、促销、食品日期 | 当商品或价格变化时，我要迅速套用模板并批量打印，避免手写和错价 | 首次打印快；CSV 批量无漏行；项目可复用 |
| 仓储/办公人员 | 资产、文件、货架、线缆标识 | 当物品入库或调整时，我要生成唯一条码/序列号并连续打印 | 扫码结果正确；序列连续；重印可追溯 |
| 家庭用户 | 收纳、姓名、提醒标签 | 当我整理物品时，我要使用易懂模板快速编辑，不学习专业排版 | 引导完成率高；空状态可行动；无需账号 |
| 高级标签用户 | 自定义尺寸、表格、图形、图片 | 当标准模板不够时，我要精确排版并控制打印参数 | 元素操作稳定；预览与纸面方向、比例一致 |
| 客服/测试人员 | 连接失败和打印异常诊断 | 当用户报告问题时，我要区分权限、蓝牙链路、协议和尺寸问题 | 诊断不触发打印；有机型、系统、错误码证据 |

## 3. 核心用户旅程

### 3.1 首次打印

1. 首次进入展示三步引导：选择模板、编辑内容、连接并打印。
2. 用户从“新建标签”“行业模板”“扫一扫/WiFi 标签”进入任务。
3. 选择标签宽高和纸张类型，或沿用模板尺寸。
4. 在编辑器添加/修改元素；撤销、重做、移动、缩放、旋转和图层调整均即时预览。
5. 点击打印后先进入预检：机型、协议、纸张类型、份数、浓度、尺寸和超界元素。
6. 未连接时进入设备发现/连接；已绑定设备优先安全复用，失效时重新发现并握手。
7. 打印成功写入历史并保留项目；失败写入失败状态和错误信息，但不自动重试已可能部分打印的任务。

### 3.2 模板复用

1. 在模板库按关键词、分类、行业筛选，列表每次加载 24 项。
2. 预览模板名称、尺寸、分类、行业和缩略图。
3. “使用模板”生成可编辑文档，不修改系统模板原本。
4. 保存为项目或“我的模板”，后续可在项目/编辑器中复用。

### 3.3 数据批量打印

1. 用户维护本地表格或导入 CSV；字段基线为 `name`、`code`、`price`、`date`。
2. 选择可绑定数据字段的模板，预览首条数据结果。
3. 系统逐行生成文档并在发送前校验二维码、条码、尺寸和元素边界。
4. 用户确认总行数、份数和目标设备后执行；异常行必须指出行号和原因。
5. 打印记录可回看，原始数据可导出备份。

### 3.4 断线恢复

1. 页面展示“连接中 / 已连接 / 已断开 / 失败”状态，不能仅依据缓存显示已连接。
2. 短时间重用执行状态核验；系统仍显示连接但特征丢失时，关闭僵尸链路后重新建立。
3. 蓝牙重新开启时可对已保存设备自动重连；用户可手动断开并忘记设备。
4. 诊断只验证适配器、服务、特征和 NIIMBOT 握手，不发送任何打印行。

## 5. 功能规格

### 5.1 模板系统

- 系统目录共 189 个模板，由基础、导入和线上模板包合并构成。
- 支持关键词、分类、行业筛选和分页加载；无结果时提供清除条件动作。
- 系统模板只读；应用模板时克隆为新文档。
- 我的模板可保存、加载和删除，最多保留 80 个；系统模板不计入此限额。
- 缩略图和素材使用小程序内压缩资源；缺图时展示可识别的占位预览，不能阻断模板编辑。

### 5.2 编辑器元素

| 类型 | 必备属性与行为 | 关键校验 |
| --- | --- | --- |
| 文本 | 内容、字体大小、粗体/斜体/下划线/删除线、水平/垂直对齐、反白、横排/竖排 | 空文本允许编辑但打印前提示；文本不越界 |
| 条码 | 内容、制式、显示文字、尺寸 | 字符集合法；模块至少占 1 个打印点；EAN-13 校验位正确 |
| 二维码 | UTF-8 内容、纠错等级、尺寸 | 内容非空；尺寸满足二维码矩阵与打印点要求 |
| 图片 | 相册选择、阈值、镜像、缩放 | 图片可读取；转换后尺寸和内存可控 |
| 矩形 | 描边、填充、线宽、虚线、边框样式 | 线宽和尺寸为正；旋转后不越界 |
| 线条 | 粗细、虚线、旋转 | 长度和粗细有效；命中区域可操作 |
| 日期 | 格式、时间/秒、偏移、生产/到期语义 | 自动更新规则明确；偏移结果可预览 |
| 序列号 | 前后缀、起始值、步长、位数 | 步长与位数合法；批次内唯一且不静默溢出 |
| 表格 | 行列数、单元格内容、边框 | 1–20 行、1–12 列；单元格数量与行列一致 |
| 素材 | 资源选择、替换、缩放、旋转 | 本地资源存在；缺失时可替换或删除 |

所有元素具有位置、宽高、旋转、锁定、图层顺序和复制/删除能力。编辑器支持长按/显式多选、整体移动、六向对齐和水平/垂直均匀分布。编辑尺寸只改变文档/预览；若超出所选打印头能力，打印预检阻断并建议兼容机型或尺寸，不允许自动裁切用户内容。

### 5.3 项目、存储与迁移

- 项目最多 120 个，按更新时间倒序；打印历史最多 80 条。
- 编辑自动保存独立于显式保存项目，崩溃或页面退出后可恢复。
- 本地 schema 版本为 2，支持从旧键 `label-printer:last-document`、`label-printer:templates`、`label-printer:profile` 一次性迁移。
- 迁移成功后移除旧键；无效宽高或未知元素被安全拒绝/忽略，不得让首页崩溃。
- JSON 备份覆盖项目、我的模板、设置、批量数据和打印历史；恢复前校验结构并二次确认覆盖风险，写入失败时回滚原数据。
- 支持导入内部 JSON 文档和 NIIM 模板 JSON；我的模板可在预览中删除，最近 10 条打印历史可重新打开标签副本。
- 存储不足时提示先备份、删除不再使用内容，不能显示“保存成功”。

### 5.4 BLE 与打印

- 支持 D11/D110 新协议、D11/D11S 旧协议、B1、B21/B21_L2B、B21_C2B、B21S/B21S_C2B 的现有协议配置。
- 连接链路包括：适配器检查、发现/选择设备、GATT 建连、服务/特征发现、通知启用、MTU/分包处理、NIIMBOT 协议握手。
- 连接管理器负责单飞复用、设备互斥、短时缓存、TTL、系统已连接复用、僵尸连接恢复、断线失效、设备记忆和诊断。
- 本项目使用 E781 服务与 NIIMBOT `0x55` 帧协议；不得接入 FF00/FF02/FF03 的 ESC/POS credit 令牌流控，因为它属于不同协议族。
- 打印必须经过栅格化、方向处理、字节对齐、打印头宽度检查和协议任务计划。
- 不自动重试可能已开始的打印任务，避免重复出纸；只在发送首个打印命令前允许透明重连。

### 5.5 状态与文案

- 首次、空项目、空模板搜索、无数据、无打印历史均有下一步动作。
- 权限拒绝、蓝牙关闭、未找到设备、握手失败、连接丢失、标签不兼容、图片失败、存储不足、CSV 错误分别给出针对性文案。
- 所有耗时动作有进行中状态并防止重复点击；打印中可以请求取消后续页，但不能声称撤回已发送数据。
- 成功反馈包含对象与结果，例如“已保存到我的标签”“3 张标签打印完成”。

### 5.6 扫码建标与扫码填充

- 首页快捷创建提供“扫码建标”：用户主动触发微信扫码后，一维码生成居中条码元素，二维码生成居中二维码元素，并以当前默认耗材尺寸进入编辑器。
- 编辑器选中条码或二维码时显示“扫描填入”；成功变更进入撤销和自动保存，取消、权限失败或类型不匹配不改变原元素。
- EAN-13 与 Code 128 根据扫码类型和内容推断，但不能绕过校验位、字符集、最小模块、尺寸和打印预检。
- 扫码内容仅在本地文档使用，不保存原始图像，不自动查询远程商品库，也不触发自动打印。
- 完整竞品依据与验收口径见 `COMPETITIVE_ANALYSIS.md` 和 `FEATURE_SPEC_SCAN_TO_LABEL.md`。

## 6. 验收标准

### P0：发布阻断

- 189 个系统模板均可构建文档；随机抽样及边界模板能进入编辑器且无缺失关键字段。
- 10 类元素都能创建、编辑、保存、恢复和渲染；条码/二维码非法内容在打印前被阻断。
- 扫码建标和扫码填充在 Android/iOS 上完成允许、拒绝、取消和恢复验证，样张由独立扫码器读回且与真值一致。
- 项目、我的模板、设置、数据、历史、自动保存及 v1→v2 迁移通过自动化测试。
- 页面无失效点击、未实现事件处理器或无法返回的模态层。
- 目标标签超打印头或尺寸非法时阻断打印，文档本身不被改写。
- 已连接缓存失效、断线和蓝牙开关恢复不会留下“假已连接”；诊断不出纸。
- 指定 Android/iOS × D11/D110/B1/B21 系列真机矩阵通过，且实物内容、方向、尺寸、份数一致。
- 使用正式 AppID 在微信开发者工具完成编译、预览和真机调试；隐私声明、权限用途、类目、品牌/素材授权通过审核。

### P1：上线前应通过

- 模板筛选、项目搜索、CSV 导入/导出、批量生成、备份/恢复和打印历史完整可用。
- 低端 Android 与主流 iPhone 上编辑手势、长列表和 300 张连续打印无明显卡死或内存告警。
- 所有错误状态可恢复，用户无需清空微信数据；帮助中提供设备、权限和耗材排查。

### P2：发布后优化

- 云同步、跨设备备份、模板收藏、更多字段映射、可访问性字号、运营推荐和匿名质量指标。

## 7. 产品指标与数据原则

如后续接入统计，只采集完成产品改进所需的最小事件，且必须先更新小程序隐私保护指引。建议指标：首次编辑完成率、打印预检通过率、连接成功率、握手失败率、打印成功率、重连恢复率、模板使用率、CSV 异常率和 7 日项目复用率。

当前本地版不应上传标签内容、条码/二维码值、图片、蓝牙设备标识或备份文件。日志默认只保留脱敏机型族、系统版本、阶段、错误码和耗时；设备 ID 必须散列或截断。

## 8. 非功能要求

- 主包保持在微信当前限制内并预留至少 10% 余量；每次资源同步后重新测量。
- 编辑和模板浏览在离线状态可用；只有微信平台能力和 BLE 依赖系统服务。
- 本地数据恢复失败不能覆盖原数据；先验证、再原子写入。
- 动态内容不得通过 `eval` 执行；CSV/JSON 导入视为不可信输入。
- 不在仓库、日志或备份中包含 AppSecret、用户隐私数据和生产凭据。
