# 商跃标签 — 短产品方案（交 Lead）

日期：2026-08-16  
作者：产品经理  
约束：不改业务代码；不把精臣爬取稿改名冒充商跃原创。  
详稿：`SHANGYUE_PRODUCT_DEFINITION.md`

---

## 1. 一句话定位

商跃标签是独立的本地标签工具：选纸、改字、扫码、连机、打印。兼容常见精臣 / NIIMBOT 热敏机，但不是精臣官方应用，也不卖精臣模板库。

## 2. 首发范围

| 端 | 做到哪 | 不做到哪 |
| --- | --- | --- |
| 小程序 `1.0.0-rc.1` | **唯一对外 RC。** 壳改名商跃；闭环保留（空白 / 扫码 / 编辑 / 预检 / BLE 打印 / 本地项目与备份）。货架只开确认自有的种子 + 用户模板。精臣远程目录、固化包、导入 NIIM 包默认关。 | 不宣称 189 / 上万套；不配生产环境打精臣 CDN；无 AppID、真机矩阵、隐私类目则仍是内部候选，不是商店上架。 |
| Web / `niim-label-app` | **不是 RC。** 只允许内部修：BLE 必须校验 NIIMBOT 通道；禁止 `slice(0,80)` 删用户项目。品牌与来源规则与小程序同一套。 | 不体验版、不上架、不把精臣目录当卖点。两个 P1 没修完之前，Web 不进入候选讨论。 |

## 3. 品牌：改什么，留什么

改成商跃（用户可见壳）：

- 小程序名、导航栏、首页标题、Web title、关于 / 引导 / 商店简介
- lockup：去掉「N」和「精臣标签」，改为「商」或「SY」
- 禁用：「精臣官方」「官方同款」「授权精品」「189 个商跃模板」
- 自有种子里的占位字（如「精臣生态」「NIIMBOT 牛肉三明治」）改成虚构商户，这是清文案，不是换皮模板

协议与硬件名必须留着（事实，不是品牌冒充）：

- NIIMBOT / 精臣作为**机型与协议**名称：D11、D110、B1、B21，E781 服务，`0x55` 帧
- 预检 / 帮助可写：「支持常见精臣热敏机（已测机型为准）」
- 关于页必须写：商跃是独立产品，与精臣无隶属或代理关系

兼容打印机 ≠ 获得内容授权。

## 4. 模板策略

| 类别 | 怎么处理 | 禁止 |
| --- | --- | --- |
| 自有 | 只留 `baseTemplates` / `template-layouts.js` 里确认是自己排的版式。清洗占位文案后，货架名「商跃模板」。数量按过审名单计，不写 189。 | 不得把精臣包改个名字塞进来凑数。 |
| 用户创建 | 「我的模板」：空白、用户另存、用户自己导入的 JSON。属于用户。 | 另存精臣来源稿不能变成「商跃原创」；来源跟着副本走。 |
| 精臣内容 | `online-niim`（153）、`niim-import`（4）、`remote-niim` 在线目录、精臣 OSS 素材：默认关。内部对照包若打开，必须独立分区且每条标「精臣来源」。无书面授权不开生产目录、不写「已授权」。 | **禁止换位置、改名、去 VIP、混进商跃精选来规避。** Lead 已否决，产品维持否决。 |

工程目录现为 211 = 54 个内置基础结构（其中 22 个已完成商跃原创登记）+ 157 个精臣来源模板。其余内容不能因缺少 `source` 就自动算作商跃原创。

## 5. 近两周优先级（5 条）

1. 小程序对外壳改名：标题、lockup、引导、帮助、关于；删「189」「官方」口径。
2. 默认关掉精臣远程目录和固化 / 导入包；对外货架只留自有种子 + 我的模板。
3. 自有种子过一遍：去掉精臣占位字；拿不准是不是自己排的，先下架，不改名顶上。
4. 小程序发布门禁推进：正式 AppID、隐私 / 类目、真机打印矩阵（D11/D110/B1/B21）。内容收窄后，精臣域名不再挡对外 RC。
5. Web 只修两个正确性问题（通道校验、批量截断删项目），不并行做品牌上架。

## 6. 需要用户拍板（3 个）

1. **自有种子名单：** 54 套 `baseTemplates` 必须逐套保留来源记录；其中 22 套 `shangyue-*` 已登记为洁净室原创，其余 32 套仍需完成逐套审查。
2. **内部包要不要留精臣参考库：** 对外关死即可，还是内部体验版也必须关死（连角标「精臣来源」都不留）？
3. **Web 本轮目标：** 只当内部修 bug 的工程树，还是修完两个 P1 后做同品牌内测（仍不上商店）？
