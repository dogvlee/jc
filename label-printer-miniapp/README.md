# 商跃标签微信小程序

商跃标签是一个本地优先的微信小程序，用于选模板、编辑标签、保存复用和通过 BLE 连接热敏打印机。标签、项目、批量数据及打印历史保存在当前设备，可先使用本地功能，也可在「我的」使用微信手机号登录。账号由自有 HTTPS 服务校验，登录不代表标签已云同步。商跃是独立产品，与精臣 / NIIMBOT 无隶属或代理关系。

当前版本为 `1.0.0-rc.1` 工程候选，**尚不能据此认定已经可以向普通用户正式开放**。本次产品审计和主流程重构说明见[产品可用性与架构收口](./docs/PRODUCT_READINESS_REFACTOR.md)，实际微信模拟器检查见[2026-09-16 验收记录](./docs/ACCEPTANCE_2026-09-16.md)。正式 AppID、Android/iOS 真机及目标打印机样张仍需要对应版本的验收证据。

## 当前功能范围

- 底部导航为首页、模板、新建、标签、我的；批量制标从“我的”进入，编辑器为独立页面。
- 「我的」提供微信手机号快捷登录、协议阅读、登录状态恢复及退出；身份与标签仓储独立，退出保留本机标签。自有后端位于 `server/`，实际服务地址与微信服务端密钥需配置后才能真实取号，见[登录接入](./docs/LOGIN_SETUP.md)。
- 首页包含最近标签、当前纸张及商跃模板；支持空白新建、模板复用、扫码建标和 Wi-Fi 码编辑。
- 电脑上的「标签设计器」（打印模板设计器网站 / 电脑版）画的标签：首页「扫码建标」扫它「发到手机」的码直接导入并打开；带图片的走模板页「导入模板」选文件。约定见[电脑标签设计器导入](./docs/PC_LABEL_DESIGNER_IMPORT.md)。
- 对外模板货架包含通过代码登记的商跃原创 / 授权改编模板、按场景与纸张生成的预设，以及用户自己的模板。预设组合数量不代表独立人工设计数量，代码标记也不代替授权凭证。
- 编辑器支持文本、条码、二维码、图片、矩形、线条、日期、序列号、表格和素材，提供撤销重做、移动缩放、旋转、多选及对齐。
- 当前素材和边框面板使用商跃内置矢量素材及程序化边框；不把内部第三方在线目录作为公开功能。
- 项目 / 用户模板保存在本机，提供草稿恢复、CSV 批量生成、打印历史和 JSON 备份恢复。JSON 备份保存文档数据及图片路径，不包含本地图片文件本体，不承诺完整的跨设备图片迁移。
- 打印前检查尺寸、编码内容和机型；超过打印头能力时阻止发送，不自动裁切标签。
- 蓝牙层提供设备记忆、连接复用、断线失效和恢复重连；首次连接由用户主动发起，已记忆设备可在下次启动或蓝牙恢复时自动重连。
- 可按需加载开源字体；远程字体和用户主动导入的远程图片依赖网络，不能把全部编辑素材宣称为始终离线可用。

## 本地检查

```powershell
cd D:\vibecode\jc\label-printer-miniapp
npm.cmd ci
npm.cmd run verify
```

`verify` 执行静态检查、Node 回归测试和商跃公开包构建。静态检查包含 JS / JSON、WXML 事件绑定、资源引用和上传集合包体；公开包内容门禁排除内部研究用第三方模板与资产。输出应与候选提交一起归档。

需要覆盖率或重新构建二维码依赖时，可分别执行 `npm.cmd run test:coverage`、`npm.cmd run build:vendor`。本地自动化不覆盖完整微信 UI、真实权限弹窗、Canvas 平台差异或物理打印质量。

已安装并登录微信开发者工具、开启 CLI 调用后，可执行真实模拟器主流程检查：

```powershell
npm.cmd run test:wechat -- --cli 'D:\software\微信web开发者工具\cli.bat' --lib 2.32.3
```

脚本创建独立的游客验收项目，使用实际 WXML 按钮和输入框验证布局、新建、保存、草稿恢复、重开、打印预检及模板入口，并核对模板截图与原始点阵的内容比例。JSON 结果与截图存于 `artifacts/wechat-smoke/run-*/`；不清除现有项目数据，不连接打印机，不上传。`--lib` 必须指定明确的 `x.y.z` 版本，报告核对实际运行的 SDK 版本。

## 微信开发者工具与发布

1. 从本项目根目录导入，保留 `project.config.json` 的 `packOptions.ignore`。不要另建丢失排除规则的工程，也不要直接复制完整 `miniprogram/` 上传。
2. 核对工程中 AppID `wxba51f65eb2f643e7` 的使用权限；独立模拟器测试使用 `touristappid`。发布配置开启合法域名检查，并按实际启用的账号服务、远程字体及导入图片来源配置网络域名。
3. 在最低支持基础库和目标基础库分别编译，验证首页、编辑器、数据恢复和各模态层。
4. 配置与实际处理数据相符的隐私指引、权限用途和服务类目；核对公开模板与素材的授权记录。
5. 在 Android / iOS 和拟支持打印机上执行首用、保存重开、断线重连、拒绝权限后恢复及打印样张验收，记录真实结果。
6. 使用 `npm.cmd run release:shangyue` 生成公开包，以命令输出的本次目录为准；已有目录保留，新产物会加时间戳。通过 `npm.cmd run release:wechat -- --appid 实际小程序AppID` 生成可直接导入的独立验收项目，详见[微信验收项目准备](./docs/WECHAT_ACCEPTANCE_SETUP.md)。

工程检查通过、公开包内容检查通过、微信和硬件验收通过是不同结论，不能互相替代。[验收记录模板](./docs/ACCEPTANCE_RECORD_TEMPLATE.md)中的空表不是已验收证据。

## 协议与硬件边界

小程序使用 BLE，不支持经典蓝牙 SPP。只支持 ESC/POS 热敏打印机（58mm / 80mm），精臣（NIIMBOT）协议已删除（ADR-015）。

任何蓝牙设备都可以连接，连上后保持连接（ADR-013）。打印按 ESC/POS：先 `ESC @`，再分条发送 `GS v 0` 图像，每张后按纸张类型 `GS FF` 走到下一张，或在连续纸上走纸约 20 mm（ADR-014、ADR-015）。型号只有“58mm 打印机”和“80mm 打印机”，按蓝牙名末尾 58/80 自动选，默认 58mm，可在打印弹层“打印机型号”中改选。对外支持机型应以手机、打印机和样张的实测组合为准。
