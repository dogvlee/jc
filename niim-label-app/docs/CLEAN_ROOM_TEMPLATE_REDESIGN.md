# 商跃模板洁净室重设计规范

## 目标

把第三方目录仅用于识别“用户要完成什么打印任务”，再从空白画布重新设计商跃模板。第三方模板本身不改名、不换色、不换 Logo 后继续使用。

## 允许进入需求侧的信息

- 通用业务场景，例如价签、货位、效期、线缆、档案和取件。
- 通用字段语义，例如品名、批次、日期、库位、责任人和商品码。
- 常用纸张宽高、打印方向与目标打印机能力。
- 聚合后的场景频次和字段组合，不保留第三方模板 ID。

## 禁止进入设计侧的信息

- 第三方缩略图、图片、图标、边框、字体文件或品牌元素。
- 单张模板的元素坐标、层级、间距、完整构图或装饰组合。
- 第三方特有文案、真实电话、网址、商品编号和二维码内容。
- 通过轻微改色、镜像、位移或替换品牌形成的近似版本。

## 商跃原创记录

每张新模板必须带有：

- `origin: shangyue-original`
- `authorship: shangyue-clean-room`
- `copyright: © 2026 商跃`
- 独立的 `taskId`、`variantLabel` 和布局签名
- 用户需要修改的文本、条码或二维码 `requiresInput` 标记
- 纸张尺寸、适配机型和打印前置检查信息

## 生成与验收流程

1. 需求侧把聚合目录整理为匿名任务 schema，只保留通用字段和尺寸。
2. 设计侧从商跃设计系统选择信息层级、分区和码区策略，重新计算全部坐标。
3. 同一任务的多个版式必须具有不同的信息结构，不能只替换文案。
4. 自动检查品牌词、远程资源、真实联系方式、越界、重复布局和码制质量。
5. 在 360 px 手机界面检查搜索、筛选、预览、编辑和打印前确认。
6. 目标打印机实打通过后，才可标记为对应机型已验证。

> 本规范用于产品与工程的来源隔离和质量门禁，不替代正式法律意见。书面授权待补的第三方内容仍不得进入公开货架。
